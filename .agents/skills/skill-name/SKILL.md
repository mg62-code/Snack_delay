# Ziel

Setze angefragte Änderungen im Repository konsistent und nachvollziehbar um.

# Vorgehen

1. Analysiere zuerst die Anfrage und identifiziere betroffene Dateien, Risiken und Abhängigkeiten.
2. Prüfe vorhandene Projektregeln (z. B. AGENTS.md, Style-Guides, Tests), bevor du Änderungen machst.
3. Implementiere die kleinste sinnvolle Änderung, die die Anforderung vollständig erfüllt.
4. Führe passende Prüfungen aus (Linting, Tests, Build), die zur Änderung passen.
5. Dokumentiere im Abschluss kurz:
   - was geändert wurde,
   - welche Prüfungen ausgeführt wurden,
   - welche offenen Punkte oder Grenzen bestehen.

# Qualitätskriterien

- Halte Änderungen fokussiert und vermeide unnötige Nebeneffekte.
- Nutze verständliche Benennungen und konsistenten Stil.
- Stelle sicher, dass neue oder geänderte Inhalte direkt zur Anfrage beitragen.
